# Changelog

## 0.17.8 — GitHub-ready release

- Added a public product-focused README and explicit Firefox-only support statement.
- Added privacy, security, support, contributing, install, compatibility, release, and AMO-preparation documentation.
- Added cross-platform Node test orchestration and deterministic Python release packaging.
- Added release consistency checks and SHA-256 artifact manifests.
- Added GitHub CI, tag-driven release automation, issue forms, and pull-request checklist.
- No streaming-controller behavior changes from 0.17.7.

## 0.17.7 — 1440, Please

- Corrected the product branding to **1440, Please** everywhere user-facing.
- Preserved the one-line promise: **“Keeps YouTube stable at 1440p.”**
- Updated popup, settings, manifest/action title, docs, tests, and release filenames.
- Streaming/controller behavior is unchanged from 0.17.6.

## 0.17.6 — Focused UI

- Introduced the focused minimal UI, live Buffer/Quality/Stage ticker, fixed activity slot, warm-orange visual language, and simplified settings surface.
- Removed Ignore Shorts as a user preference while leaving Shorts untouched internally.
- Streaming/controller behavior remained unchanged from 0.17.5.
