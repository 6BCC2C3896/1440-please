# Support

## Playback bug

Open a GitHub issue using the **Playback bug** template. Include:

- Firefox version;
- extension version;
- Defensive or Aggressive mode;
- current/target quality;
- approximate buffer behavior;
- whether the problem occurs at startup, during ramp-up, or after a stable 1440p period.

## Installation problem

Read [docs/INSTALL.md](docs/INSTALL.md) first. The most common confusion is Mozilla signing: an XPI built locally or by GitHub Actions is not automatically signed for normal Firefox Release/Beta installation.

## Feature request

Please keep requests aligned with the project's narrow job: stable 1440p YouTube playback in Firefox. General YouTube enhancement features are likely out of scope.
